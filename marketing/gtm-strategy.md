# Go-To-Market Strategy

Positioning (one line): **Persistent memory for AI coding agents that stays cheap** — the context-memory kit for multi-project developers.

Differentiator: the explicit **token-cost model** (always-on / on-demand / zero-cost tiers). Others ship "context files"; we ship *memory that doesn't blow up your token bill*.

## 1. Content-led / developer marketing (cheapest, highest fit)
- Launch blog post (`marketing/launch-post.md`) + a demo GIF from `demo/demo.sh` showing a fresh session recalling cross-project facts.
- Distribute: Show HN, r/LocalLLaMA, dev.to, X. Developers adopt tools they read a good writeup about.
- CTA: one-command install; ask for feedback from multi-repo users.

## 2. Ride the Kiro / agent ecosystem
- List wherever AI-agent community tools are shared; engage the relevant agent communities directly.
- Be *the* context-memory kit for a specific agent — a defensible niche beats a generic one.

## 3. Freemium wedge (commercial rights reserved by BSL)
- Free: the kit for individuals/internal use.
- Paid: (a) team/hosted version — shared registry + KB sync; (b) done-for-you onboarding; (c) workflow template packs (research labs, agencies).

## 4. Validate before over-investing
- Get 5–10 real users. If they still use it after a week, it's a product; if not, you learned cheaply.
- Instrument: track installs, `add-project` usage, and week-2 retention via a lightweight opt-in.

## 5. Provenance / PR
- The authentic story — "I built persistent memory for my AI and it 10x'd my multi-project research" — is the narrative. It's verifiable and shows the tool doing real work.
- Establish provenance: git authorship + dates, the novelty write-up in `docs/paper/`, and the launch post as a public timestamp.

## Sequencing
Week 0: polish + demo GIF. Week 1: Show HN + dev.to. Weeks 2–3: engage niche communities, collect 5–10 users, measure retention. Week 4+: if retained, build the team/hosted wedge.
